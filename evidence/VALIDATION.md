## 1. 素材生成与派生（本轮重做，可复现口径）

- **成片**：用图像生成工具生成一张 1536×1024 的原创概念图。提示词要点：东方仙侠动画电影质感；
  一位身姿挺拔的年轻剑客侧身立于断崖残台，面容清朗、长发后扬，玄青与银白交织的战甲，
  银白披风向画面右侧舒展如出鞘刀锋，斜持一柄泛冷冽青光的长剑；背景为破云而下的天光、
  翻涌云海与悬浮的东方楼阁。**明确排除**面具、骷髅、尖刺、血月、文字与 logo，并要求人物
  面部保持正常人类比例——这是上一版被否掉的具体原因，已固化为提示词约束。未指名任何既有角色。
- **统一尺寸**：从顶部裁成 16:9（1536×864，同时去掉生成工具落在右下角的角标），
  再等比缩放到 2048×1152，作为五张资产的共同像素源。
- **前景蒙版**：以「人物 + 长剑」和「向右展开的披风」两块多边形轮廓的**并集**作为总前景 F，
  保证三层叠加后能完整还原成片、不留缺口；轮廓内再按暗部 / 高频 / 冷色权重把 F
  互补切成两张 RGBA（披风、人物），RGB 全部直接取自成片。本版披风为银白半透明，
  原先按红色判定的权重已失效，改用「高频褶皱 + 冷色偏移」判据；并把「披风专属区」
  （在披风轮廓内、又不在人物轮廓内）优先归给披风层，否则半透明权重会把飘带摊薄到
  图层解构时几乎看不见 —— 这是重做时实际踩到并修掉的问题。
- **远景底板**：把 F 区域在 72×40 的低分辨率上做各向同性**扩散填充**（边界颜色向内推进），
  再对小图高斯模糊、放大回原尺寸，并从右下角无前景的云海取高频平铺注入，最后按行亮度补偿、
  以 28px 羽化回贴。单独查看远景层时，修补区仍是一块比周围略亮的云区 —— 这是非生成式修补的
  固有痕迹，页面「技术边界」已如实标注，不做二次美化。
  过程中试过「同水平插值」与「512px 扩散」两种方案，分别留下拖影条纹与方块台阶，均已弃用并记录在此。
- **深度分段图**：由两层 alpha 编码生成同一张 PNG —— R 通道为粗略分层
  （远景 0.08 / 披风 0.62 / 人物 0.92），B 通道为披风自由度
  （披风 0.92 / 人物 0.10 / 远景 0.05），G 通道与配色用于绿 / 红 / 紫伪彩色查看。
  shader 只读 R 与 B，不做逐像素 UV 位移。
- **远景补洞口径**：远景底板的人物区域，由图像生成模型基于同一张成片重绘了一张同构图、无人物的背景，
  再按人物蒙版（alpha > 0.55 外扩 11px、羽化 10px）替换进底板；人物羽化带内另做一次解析反解，
  使该处的 alpha 合成结果回到成片原值。
- **还原度实测**：按 alpha 顺序叠加 远景 → 披风 → 人物，与成片的平均绝对像素误差为
  **3.99 / 255（约 1.6%）**，误差集中在人物边缘羽化带与重绘区；首屏成片另由 uPlate 全图保真参与合成。逐文件字节数与 SHA-256 见 `asset-manifest.json` 与 `src/config/assets.js`。
- 派生脚本为一次性临时工具，未随项目交付；上述参数即完整复现口径。

## 8. 诚实性声明

- 本页是**个人技术项目**，产品官网只是演示目标形态。页面不含企业名称、联系方式、
  客户案例、报价或服务承诺；页脚与「项目边界声明」均已注明，且由自动检查拦截回退。
- 主视觉为本项目用图像生成工具产生的**原创概念成片**，未使用第三方作品素材或既有角色形象；
  人物、战甲、披风、楼阁与云海**非项目代码绘制**，也不主张为作者手绘。
- 五张纹理是**由同一张成片派生的图层**，不是外部下载的独立绘制素材；远景层的前景区域
  为程序化柔化修补，单独查看时可见，未做二次美化。代码原创范围仅限分层合成、Shader、
  状态机、交互、资产派生流程、产品页信息架构与工程实现。
- 深度分段图是伪彩色分区编码，不是物理深度；只作分段权重，不参与逐像素位移。
- 素材虽为本项目自行生成，生成平台对输出物的商用条款**仍待确认**，因此不作可商用或
  已获授权的表述，当前仅用于个人技术演示。
- 构建成功 ≠ 视觉、交互、性能全部通过；上文逐项区分了实测与未实测。
